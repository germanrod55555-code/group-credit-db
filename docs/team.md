## Личная история Git

Репозиторий опубликован 19.11.2026: https://github.com/germanrod55555-code/group-credit-db. Три исходных коммита сохранены без изменения авторов, дат и идентификаторов. История пока содержит коммиты Германа; коммитов, приписанных Игорю и Павлу, нет.
Для выполнения требования преподавателя каждому нужно внести собственное содержательное изменение, проверить его и закоммитить из своего аккаунта.
Менять автора чужого коммита и переносить даты в прошлое не нужно.

1. Каждый регистрируется/входит в GitHub и сообщает логин тимлиду.
2. Тимлид добавляет Игоря и Павла в существующий репозиторий `group-credit-db` после получения их GitHub-логинов. Репозиторий открытый: преподавателю для чтения достаточно ссылки, отдельное приглашение не требуется. Права изменения участникам пока не предоставлены.
3. Участник клонирует репозиторий, задаёт свои `user.name` и подтверждённый email, создаёт ветку.
4. Павел проверяет карту данных, дополняет объяснение двух запросов и воспроизводит их результат.
5. Игорь проверяет запреты ролей, восстановление копии, дополняет протокол администрирования.
6. Герман проверяет загрузку и выгрузку, обновляет протокол производительности.
7. Каждый делает коммит после своего действия и открывает pull request. Тимлид проверяет и объединяет.

Пример веток: `analysis/pavel`, `admin/igor`, `development/german`.
Не объединять через squash, если нужно сохранить отдельные авторские коммиты.
Все трое читают `docs/defense/questions.md`: на защите предусмотрены вопросы по чужой роли.
