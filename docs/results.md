До оптимизации крупные таблицы читаются последовательно. После неё селективные условия обслуживаются B-tree. Для ТОП-5 индекс начинается с года, затем идёт прибыль по убыванию и ID: он позволяет взять первые пять записей без сортировки всего годового набора. Индекс borrower_id быстро получает их долг. Для месяца используется диапазон дат; для банка - равенство lender_id; для региона - равенство коду. INCLUDE предоставляет столбцы из индекса, а VACUUM поддерживает возможность Index Only Scan. PK/UNIQUE индексы были и до оптимизации.

Поля Actual Rows и Actual Loops в полном плане позволяют оценить повторную работу узлов. Shared Hit Blocks - обращения к страницам, найденным в буферном кэше, а не число уникальных страниц. Shared Read Blocks - чтения в буферы; это не гарантирует физический ввод с диска из-за кэша ОС. Время чтения и временные блоки следует смотреть в JSON, не складывая буферы родителя с дочерними узлами.
